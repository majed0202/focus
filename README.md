# focus

متجر إلكتروني مع لوحة تحكم كاملة، مبني بـ HTML/CSS/JavaScript بدون خادم، ويعمل على GitHub Pages.
الطلبات ترسل عبر واتساب، وكل المحتوى (المنتجات، النصوص، الألوان، الروابط، رسالة الطلب) قابل للتعديل من لوحة التحكم.

## هيكل المشروع

```
maison-or/
├── index.html            ← صفحة المتجر
├── admin.html            ← لوحة التحكم
├── css/
│   ├── style.css         ← تصميم المتجر (الألوان تُقرأ من settings.json)
│   └── admin.css         ← تصميم لوحة التحكم
├── js/
│   ├── config.js         ← هاش كلمة مرور لوحة التحكم
│   ├── common.js         ← أدوات مشتركة (تحميل، قوالب الرسالة، تطبيق الألوان)
│   ├── store.js          ← منطق المتجر والسلة والطلب
│   └── admin.js          ← منطق لوحة التحكم والنشر إلى GitHub
├── data/
│   ├── settings.json     ← إعدادات الموقع (النصوص، الواتساب، الألوان، الروابط، الأقسام)
│   └── products.json     ← المنتجات
├── images/               ← صور المنتجات (اختياري)
├── .nojekyll             ← يتيح لـ GitHub Pages نشر كل المجلدات
└── README.md
```

## ما الذي يمكن التحكم به من لوحة التحكم
- **المنتجات:** إضافة، تعديل، حذف، إخفاء/إظهار، ترتيب بالأسهم، سعر ومخزون، صورة، شارة، وصف، ورابط المنتج.
- **النصوص:** اسم المتجر، الشعار، عنوان الواجهة، النصوص، زر الواجهة، عنوان القسم، نص الفوتر.
- **الواتساب:** رقم الاستقبال، العملة، الرابط الإضافي للطلب، شكل سطر المنتج، قالب الرسالة بالكامل.
- **الأقسام والروابط:** إظهار/إخفاء الواجهة والمنتجات، وروابط القائمة العلوية.
- **الألوان:** سبعة ألوان للتصميم تُطبَّق على المتجر مباشرة.
- **النشر:** مباشرة إلى GitHub، أو تصدير/استيراد ملفات JSON يدوياً.

## متغيرات قالب الرسالة
- في `whatsapp.itemFormat`: `{name}` اسم المنتج، `{qty}` الكمية، `{price}` السعر، `{subtotal}` المجموع الفرعي، `{link}` رابط المنتج.
- في `whatsapp.template`: `{items}` كل المنتجات، `{total}` المجموع، `{orderLink}` الرابط الإضافي، `{brand}` اسم المتجر.

## الإعداد الأول
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `maison-or`) وارفع كل الملفات بنفس الهيكل، مع الحفاظ على `.nojekyll`.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main` / root.
3. الموقع: `https://USERNAME.github.io/maison-or/`
4. لوحة التحكم: `https://USERNAME.github.io/maison-or/admin.html`
5. ضبط كلمة المرور: افتح المتجر، اضغط F12 ثم Console، والصق:

   crypto.subtle.digest('SHA-256', new TextEncoder().encode('كلمتك')).then(b=>console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))

6. انسخ الناتج وضعه في `js/config.js` مكان `PUT_YOUR_SHA256_HASH_HERE`.
7. عدّل `data/settings.json` برقم واتساب الحقيقي والعملة، أو من تبويب الإعدادات.

## النشر المباشر من لوحة التحكم (اختياري)
1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
2. Repository access: Only select repositories → اختر مستودع المتجر فقط.
3. Permissions → Repository permissions → Contents: Read and write.
4. في لوحة التحكم → تبويب "النشر": أدخل اسم المستخدم واسم المستودع والفرع والتوكن، ثم اضغط "نشر التغييرات".
5. التوكن يُحفظ في الجلسة الحالية فقط (يُمسح عند إغلاق المتصفح أو الخروج).

## النشر اليدوي (بديل)
1. في لوحة التحكم → تبويب "النشر" → "تصدير الملفين".
2. استبدل `data/settings.json` و`data/products.json` في المستودع وارفع التغيير (commit).

## ملاحظات
- التعديلات قبل النشر تُحفظ كمسودة في متصفحك فقط، ويظهر تنبيه حتى تنشرها.
- بعد النشر قد يتأخر ظهور التغيير دقيقة أو دقيقتين بسبب تخزين GitHub Pages.
- الصور: استخدم روابط صور مباشرة، أو ضع الصور في مجلد `images/` واستخدم مسارها النسبي (مثل `images/bag.jpg`).

## ملاحظة أمنية
GitHub Pages موقع ثابت، لذا حماية لوحة التحكم على مستوى المتصفح فقط، وهاش كلمة المرور مكشوف لمن يقرأ الكود. اختر كلمة مرور قوية، ولا تستخدم توكناً بصلاحيات أوسع من المستودع. للحماية الحقيقية استخدم خادماً أو خدمة مثل Supabase مع تسجيل دخول فعلي.
